# 👻 xGhost Copilot — Скрытный ассистент для онлайн-собеседований

[English Documentation](README.md) • [🌐 Веб-сайт](https://xghost.vercel.app) • [📦 Скачать релизы](https://github.com/your-username/xghost/releases)

> **Бесплатный open-source оверлей для прохождения технических интервью.**
> Ответы на естественном языке Senior-разработчика (без «ИИшности»), моментальное распознавание задач с экрана (LeetCode, тесты, архитектура) и аппаратная невидимость при демонстрации экрана в Zoom, Google Meet и Teams.

---

## ⚡ Особенности

- 🛡️ **Аппаратный Stealth-режим**: Использование macOS `NSWindowSharingNone` (`setContentProtection(true)`). Окно приложения физически не попадает в буфер захвата экрана Zoom / Meet / Teams / Slack.
- 🗣️ **Anti-AI движок ответов**: Никаких "В заключение...", "Безусловно, React — это библиотека...". Скрипты от 1-го лица, панчлайн за 1 секунду, предупреждения о вопросах-ловушках и боевые аргументы из продакшена.
- 👁️ **Режим «Суфлер» (Teleprompter)**: Окно сворачивается в узкую полоску под глазок веб-камеры. Ты читаешь тезисы, сохраняя прямой зрительный контакт с интервьюером.
- 🎙️ **Аудио-распознавание**: Захват вопроса собеседника на лету (Web Audio + Web Speech API / Groq Whisper).
- 📸 **OCR Захват экрана**: Мгновенный захват условий задач, кода и диаграмм по `⌘ + ⇧ + S`.
- 🔑 **BYOK (Bring Your Own Key)**: Поддержка бесплатных Gemini 2.0 Flash и Groq (Llama 3.3 70B), а также OpenAI GPT-4o и Claude 3.5 Sonnet. Никаких платных подписок.

## 🚀 Быстрый старт

### Готовые файлы (Releases)
1. Скачай `.dmg` (для Mac Apple Silicon M1/M2/M3/M4) или `.exe` (для Windows) из вкладки **Releases**.
2. Открой приложение, нажми иконку ⚙️ Настройки и вставь бесплатный ключ от Google AI Studio или Groq.
3. Готово! Пользуйся оверлеем во время собеседований.

### Запуск из исходного кода
```bash
git clone https://github.com/your-username/xghost.git
cd xghost
npm install
npm run dev:electron
```

## ⌨️ Горячие клавиши

| Горячая клавиша | Действие |
|-----------------|----------|
| `⌘ + ⇧ + Space` | Показать / скрыть оверлей |
| `⌘ + ⇧ + S` | Захватить область экрана (код/задача) |
| `⌘ + ⇧ + R` | Вкл/выкл распознавание речи |
| `⌘ + Enter` | Сгенерировать ответ |
| `⌘ + ⇧ + ↑ / ↓` | Регулировка прозрачности окна |
| `⌘ + ⇧ + X` | **Panic Button**: мгновенно скрыть окно |
